# Password Manager - Backend

The backend of a full-stack Password Manager application built with Node.js, Express.js, and MongoDB.

##  About

This backend was built to practice Node.js, Express.js, REST APIs, and MongoDB integration with a React frontend.

##  Features

- REST API for password management
- Add password data
- Retrieve saved passwords
- Update password data
- Delete password data
- MongoDB database integration

##  Technologies

- Node.js
- Express.js
- MongoDB
