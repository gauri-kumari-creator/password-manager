# Password Manager - Frontend

The frontend of a full-stack Password Manager application built with React.js and Tailwind CSS.

##  About

This frontend was built to practice React.js, component-based development, API integration, and responsive UI design.

##  Features

- Add passwords
- Edit passwords
- Delete passwords
- View saved passwords
- Responsive user interface
- Connects with backend APIs

##  Technologies

- React.js
- JavaScript
- Tailwind CSS
