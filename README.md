# Password Manager

A full-stack Password Manager application built with React.js, Node.js, Express.js, and MongoDB.

##  Features

- Add passwords
- View saved passwords
- Edit passwords
- Delete passwords
- MongoDB database integration
- Responsive user interface
- Frontend and backend integration

##  Technologies

### Frontend
- React.js
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB

##  Project Structure

- `passOP/` — Frontend
- `passOP mongo/backend/` — Backend

##  Project

This project was built to practice full-stack web development, React.js, backend APIs, Express.js, and MongoDB integration.
